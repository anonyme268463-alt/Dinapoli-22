# Di Napoli Lamballe — Refonte

Prototype moderne et responsive du site de commande en ligne de Di Napoli Lamballe.

## Fonctionnalités

- Carte organisée par catégories
- Recherche de produits
- Choix du mode de commande
- Tailles Junior, Senior et Méga
- Panier interactif avec quantités et total
- Visuels officiels optimisés au format WebP
- Interface adaptée au téléphone et à l’ordinateur

## Ressources

Les visuels autorisés du site actuel sont classés dans `assets/img`, `assets/images` et `assets/produit`.

## Publication

Le projet est compatible avec GitHub Pages : branche `main`, dossier racine `/`.

> Prototype de présentation : les commandes et paiements ne sont pas transmis.
